# 🎯 Syntax Striker

**Syntax Striker** is an educational crossword puzzle game designed to make programming concepts more interactive and engaging. Instead of learning programming concepts only through traditional methods, the project uses crossword-based puzzles to help students improve their understanding of programming terminology and concepts.

## 📌 Project Overview

Syntax Striker allows users to solve programming-related crossword puzzles by selecting a programming language and choosing the desired puzzle dimensions.

The project focuses on **learning through problem-solving**, where users recall programming concepts, keywords, and terminology while completing crossword puzzles.

## ✨ Features

- 🧩 **Programming Crossword Puzzles**
  - Solve crossword puzzles based on programming concepts.

- 💻 **Multiple Programming Languages**
  - Select from available programming languages such as Python, C++, and JavaScript.

- 📐 **Custom Puzzle Dimensions**
  - Choose the width and height of the crossword within supported limits.

- 💡 **Clue-Based Learning**
  - Each puzzle provides clues to help users identify the correct programming terms.

- 🎯 **Interactive Gameplay**
  - Fill crossword cells and navigate through the puzzle interactively.

- 📚 **Educational Focus**
  - Reinforces programming vocabulary and concepts through active recall.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive interface
- **JavaScript** – Game logic and interactivity

## 🎮 How to Play

1. Select a programming language.
2. Choose the crossword dimensions.
3. Start the generated puzzle.
4. Read the provided clues.
5. Enter the appropriate programming terms into the crossword.
6. Complete the puzzle to reinforce your understanding of programming concepts.

## 🎓 Educational Objective

The main objective of Syntax Striker is to provide a **simple and interactive approach to programming education**.

By combining crossword puzzles with programming terminology, the project encourages:

- Active recall
- Logical thinking
- Problem-solving
- Familiarity with programming terminology
- Interactive learning
